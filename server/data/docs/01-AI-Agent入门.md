# AI Agent 入门：概念与核心能力

> 本文是知识库演示素材（2026-10-14 校准），用于检索与引用测试；能力介绍不代表本项目已实现全部功能。

AI Agent（人工智能智能体）通常指能围绕目标，利用模型、上下文和工具选择步骤并执行任务的程序。大语言模型是常见的决策组件，实际能力取决于工具、权限、状态管理与执行边界；不能保证自主完成所有目标。

## 什么是 AI Agent

Agent 可以理解需求，按步骤查询信息或调用工具，并根据返回结果调整后续行动。执行失败、信息不足或风险较高时，应明确追问、停止或交给人工。

## AI Agent 的核心能力

### 规划

规划是把目标分为可执行步骤。例如“对比三家供应商报价”可以拆成“获取报价 → 逐项比较 → 汇总差异”。每一步仍需真实来源与结果验证，不能把生成的计划当成已完成工作。

### 记忆

多轮任务需要管理上下文：

- 短期记忆：本轮和最近对话里的需求、约束与工具结果。
- 长期记忆：经授权持久化的偏好、结论和可复用经验。

保存历史、恢复 checkpoint 与将历史送入模型是不同步骤。本项目有会话/checkpoint 存储，默认 RAG 生成适配器尚未把历史注入核心 Prompt，也没有独立长期记忆系统。

### 工具调用

工具可连接知识库、数据库、业务 API 或网页。调用必须带参数校验、权限与失败处理；工具失败不能被改写成成功。只读查询与会产生业务变更的写操作应设置不同执行边界。

## AI Agent 与普通聊天机器人的区别

区别主要在于系统是否能管理状态、选择步骤并执行外部操作，而不是名称。聊天产品也可能具备检索、记忆和工具调用，Agent 也可能只有固定流程。本项目以知识问答、演示订单只读查询与人工接管为范围，暂未开放退款等写操作。
