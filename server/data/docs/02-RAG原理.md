# RAG 检索增强生成原理

> 本文是知识库演示素材（2026-10-14 校准），用于检索与引用测试；不把检索或引用范围校验视为答案正确性的证明。

RAG（Retrieval-Augmented Generation，检索增强生成）是在生成回答前检索外部资料，把相关内容作为模型上下文的方案。

## 完整链路

教学上可将流程分为八步：文档解析 → 清洗 → 分块 → 向量化 → 存储 → 检索 → 重排 → 注入生成。实际系统也会增加引用校验、权限过滤、错误处理与评测，重排可按配置跳过。

文档解析把 PDF、Word、扫描件等转为文本。清洗减少重复空行等噪声，但不保证自动去除全部页眉、页脚或乱码。分块按结构和段落组织片段；overlap 可用于保留上下文，本项目默认 overlap 为 0，超长段落保持完整。

向量化将文本映射成高维向量。向量数据库如 Qdrant、Milvus、pgvector 用于存储与相似检索；距离度量取决于索引配置，本项目使用余弦相似度。

检索时将问题向量化，取得 top-K 候选。混合检索还结合 BM25 关键词候选并用 RRF 融合，重排（rerank）再对候选排序。本项目默认检索 top 5，配置精排且调用成功时取 top 3，并按相关性阈值过滤。

## 防幻觉设计

生成 Prompt 应要求基于资料回答，并在资料不足时明确说明。正文使用 [来源N] 标记，程序验证引用序号是否在素材范围内，可发现不存在的来源编号。

引用范围合法不代表资料支持结论；没有引用也可能通过该范围检查。降低幻觉还需要资料质量、检索相关性、答案与来源的一致性评测，以及失败澄清/人工接管。本项目同步客服图支持非法引用重写，直接问答和流式问答主要返回校验结果。
